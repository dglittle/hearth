zones

Decorative colored rectangles behind the cards (+ card → kind zone). Body = the color (teal, purple, … or #3a5ba0; empty = auto — or use the color button in the editor); title spans the full width. Drag a ⌜ ⌞ corner to move the zone alone, the ⌝ corner to move it with everything inside it, the ⌟ corner to resize. Tap a corner to select, 2×tap one to edit; the body acts like empty space (drag pans, ⇧drag lassos, tap clears); lasso ignores zones.

limits dials

t1/t2 = the two subscription tokens. Per token: 5h rolling window · 7d weekly (all models) · f7d fable weekly (API bucket 7d_oi). Each row's bar = % used (green → amber ≥75% → red ≥90%); the thin blue bars show how much of the window has elapsed — one under 5h, one shared by 7d+f7d (same 7-day window). Hover any bar for exact numbers. The number at the end is how long ago the last probe ran (3m, 2h, 1d) — it re-probes when an erg finishes with this page open, on a stale page load, or when you hit ↻ (server allows one probe per 90s). The gold-boxed token is the one the most recent erg ran on; new ergs start on the token whose f7d resets soonest (per the last probe), falling back to the other on a limit hit. ☀ = Sol (ChatGPT subscription, codex CLI): 5h + wk windows, read passively from the last codex session's own rate-limit log — no probe possible, so it only refreshes when a Sol run happens (hover shows how old the reading is).
